# @mmp/schema

The contract between **MMP** (this repo, the server and panel) and **MML** (the launcher): API request and response types, the pack manifest format, `API_VERSION`, and the `mml://` connect link helpers.

This is the original. The MML repo keeps a copy, updated with `npm run sync-schema` there. See [The shared schema package](../../README.md#the-shared-schema-package).
